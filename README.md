# Egyptian Premier League Data Scraper

A web scraping toolkit to collect match results, goal details, and referee/stadium information from Transfermarkt for the Egyptian Premier League (2014-2025 seasons).

## Features
- Scrapes match results with metadata
- Extracts detailed goal information (scorers, assists, penalties, own goals)
- Collects referee and stadium data
- Handles multiple seasons (2014-2025)
- Exports data to Excel files
- Cookie management for persistent sessions

## Installation

1. **Clone the repository**
```bash
git clone https://github.com/ahmedelgohry02/egyptian-premier-league-scraper.git
cd egyptian-premier-league-scraper
```

2. Install dependencies
```bash
pip install -r requirements.txt
```
